## 7. 故障与处理

| 现象 | 处理 |
|---|---|
| 服务器直连 `github.com` 超时 | 本地 `git bundle` → `scp` → 服务器克隆；提交后再用 bundle 回传 |
| 服务器直连 Docker Hub 超时 | `COURSE_BASE_IMAGE` / `COURSE_DOCKER_CLI_IMAGE` 指向 `m.daocloud.io` 的固定摘要；DRAFT 用 `COURSE_DRAFT_IMAGE` 指向本地已有的 python 镜像 |
| Debian 官方源超时 | `COURSE_DEBIAN_ORIGIN=https://mirrors.tuna.tsinghua.edu.cn`，候选 Dockerfile 与编排镜像都改源 |
| 默认 `python:3.13-slim` 摘要未缓存 | `prepare` 前显式设置 `COURSE_DRAFT_IMAGE`，否则 DRAFT 会尝试拉取未缓存摘要 |
| `prepare` 拒绝已有样例 | 每次实验使用新克隆/新工作区，或保留原样例并换 `--out` |
| E8–E10 主分支 CI 曾因镜像站 TLS 握手超时失败 | 重跑该 job 后通过；属外部镜像站抖动，不是代码回归 |
