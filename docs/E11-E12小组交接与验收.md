## 4. 注意事项

- **必需检查已变为三项**：`e7-a-quality-gate`、`e8e10-quality-gate`、`e11e12-integration`，strict；`main` 不允许绕过，admin 也受限。
- **服务器不能直连 GitHub/Docker Hub**：仓库用 `git bundle` 进出；镜像用 `m.daocloud.io` 固定摘要；Debian 用清华源；提交后用 `format-patch` 回本机推送。
- **镜像/目录/端口按学号隔离**：`course-e11e12:<学号>`、`work/<学号>-*`、`--port 808x`；不要覆盖他人 `work/` 或复用他人 `job_id`。
- **`data/`、`work/` 不进 Git**：证据只走 tar.gz 归档；`data/sds` 是上游克隆，归档时排除。
- **报告 commit 必须与修复目标一致**：E11-B/E12 的 `input_report` 由服务端核对 `kind`、commit 和 SHA；旧报告返回 `STALE_REPORT`，不会进入修复阶段。
- **E2 旧契约差异**：E2 的 `GET /v1/artifacts/{artifact_id}` 在 E12 由 `GET /v1/jobs/{job_id}/files/{path}` + `artifact://` 取代；B09 联调按本组 `接口契约.md` 第 5 节执行。
- **真实项目口径**：SDS 是外部开源项目，不是本组自有仓库；课程样例标 `course-generated`。若课程严格要求“本组实际维护”，需向老师确认后再调整说明。
- **CI 抖动**：本次 main push 与 PR #13 的 `e8e10-quality-gate` 曾因 `m.daocloud.io` 返回异常 media type 失败，重跑后通过；连续失败时优先重跑，必要时另开 PR 把 `e8e10.yml` 的 `BASE_IMAGE` 改用 Docker Hub 固定摘要。
