# A09 库存补货判定

E13 A09 交换项目，维护人谢浩天（241250033）。代码按课程的双 C 源文件和显式 Make 规则编写。

`make test` 构建并执行库存用例。程序接收现货数和已预留数，库存不足时输出 `1`，否则输出 `0`。无参数运行使用 4 件现货和 2 件预留，预期输出 `1`。输入参数非法时退出码为 2。

预留少于 8 件时，可用库存低于或等于 3 件就提示补货。预留达到 8 件后，补货阈值提高到 5 件。

`Dockerfile.broken` 是 DRAFT 要回放的构建输入，`candidate.Dockerfile` 固定 Python 基础镜像并安装构建、Git 和跟踪工具。
